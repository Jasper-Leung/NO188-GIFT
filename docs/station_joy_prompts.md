# 驿站 3D 模型提示词（第二版）— 十六乐事

> 取代 `station_marker_prompts.md`。旧版是 10 条"路标"提示词，站名也全对不上
> （起点路标 / 东浦路标 / 南谷路标…），而 `road_data.gd` 里 16 座站叫的是
> 起程驿楼 / 东岭驿楼 / 南溪茶寮…。这一版按**十六乐事**重排，并覆盖旧版那
> 7 个手工模型 + 树：11 座非碎片站（含榕树下）+ 琴音林 = **12 条**。
> 剩下四座碎片站（茶烟小筑 / 云影台 / 竹雨庭 / 花房·禽语湖湾）已有模型，不重出。
>
> 流程：出图（中文，即梦 / 豆包）→ 存 `assets/models/` → Tripo image-to-3d
> → 导出 GLB + basecolor jpg → 改 `STATION_GLB_CONFIG` / `model_idx` → 跑回归。
> 落库清单见文末 §4。

### 两处"就近落地"（写在这里免得下一个人以为是漏了）

1. **第 7 条「隔江山寺闻钟」落在 #3 右岭岭台，但岭台上看不见江。**
   全场只有三处水，`water_data.gd` 的 `BASIN_SHAPES` 写死是站 2 / 4 / 6，而
   2 和 6 已经被「清溪浅水行舟」「暑至临溪濯足」这两条同样含水的乐事占掉。
   含"江/溪/水"的三条乐事里，两条落在有水的站上，第三条只能落在望谷的岭台上。
   所以 #3 的 `event` 建议写**「隔谷钟声」**而不是照抄原句——照抄的话玩家
   站在岭台上听见的钟声和文案承诺的江对不上，这正是"名字在骗人"那一族。
2. **第 5 条「柳阴堤畔闲行」落在 #11 左弯廊，堤指的是路肩不是水堤。**
   同一份地形约束。这条是唯一能圆过去的（廊道本来就可以是贴路的），文案里
   不提水就够。

## 2. 通用提示词尾巴（每条都接上）

即梦 / 豆包吃描述，中文长句比关键词堆砌稳。12 条共用这一段，写在每条末尾：

```
主体居中、完整入画，正面偏右三十度，米白纯色背景，
无环境、无远景、无多余道具；不出现任何人物；
不出现任何文字、牌匾、招牌、幌子、对联、石碑刻字；
单体建筑或单体树，底面平整、落地不悬空；
宽约六到八米、深约五米、高约三米半到四米半；
中国南方山地的木构与夯土白墙，屋面是**偏暖的深灰褐瓦**（不是青蓝色）；
柔和的暖秋午后侧光，材质哑光、无金属高光、无镜面反光；
写实摄影质感，浅景深，1:1 画幅，高清。
```

四条不是审美偏好，是踩过的坑：

- **「不出现任何文字」**——站名牌是 `Label3D`（`World3D._add_label()`），
  悬在**量出来的**屋顶上方。模型上再烤一块牌匾 = 玩家看见两个名字，
  而且牌匾那几厘米的字在 18m 上一个像素都读不出来。
- **「偏暖的深灰褐瓦」**——新的 Tripo 模型屋顶烤在 basecolor 里，
  `STATION_ROOF_TINT` 那套按 `<站名>_roof` 材质名匹配的运行时填色**不会生效**。
  青瓦色只能在这张图上定死。（7 个手工模型当初换掉冷灰的理由见
  `verify_station_roof.gd` 文件头。）
- **「不出现人物」**——驿站不能骑进去，站前也没有 NPC。模型里出现人物会变成
  一具比例不对的假人，而 Tripo 对人形细节的还原一向不可控。
  "有人刚来过"一律用道具表达：草鞋、掀开的壶盖、烧了一半的香、铺好的藤枕。
- **「底面平整、落地不悬空」**——`STATION_OFFSET` 是 18m，
  脚底比沥青外沿宽就会被路肩吃掉。脚底半宽还要**小于 9.4m**
  （现有 16 站实测半径 3.43~9.40m 的上限），超了玩家在路面上够不着打卡圈，
  而 `verify_interact_latch` 第 8 节才会红。

## 3. 12 条出图提示词

每条：一句画面设计 → 可直接粘的完整提示词。文件命名建议沿用手工模型那一套
（`station_<中文短名>.glb`），和 `verify_station_roof.gd` 的 `HAND_MODELS`
一个风格——反正那张表要跟着重写。

### 3.1　起程驿楼 · 接客不着衣冠

> 驿楼是头一站，玩家第一眼看见的东西。门要**大敞**，堂前石阶三级，门槛边一双
> 草鞋歪放、一把蒲扇搭在条凳上，门内一张条案当柜台、案上一只粗陶壶和一只空碗。
> "不着衣冠"的意思是**东西没摆齐**，不是画一个披头散发的人。

```
中式山地小镇的驿楼门脸，三开间木构，白粉墙，深暖灰瓦双坡顶，
正中大门完全敞开，门内一条长条案当柜台，案上摆一只粗陶壶和一只粗碗；
门外三级青石台阶，台阶边一双草鞋歪斜放着，条凳上搭一把蒲扇，
门框两侧各挂一串晒干的辣椒，不挂灯笼不挂招牌；
单人主体，正面偏右三十度，米白纯色背景，柔和暖秋午后侧光，
不出现任何人物，不出现任何文字、牌匾、招牌、幌子、对联、石碑刻字；
底面平整落地，宽约八米，深约六米，高约四米五；
材质哑光无金属高光，写实摄影质感，浅景深，1:1 画幅，高清
```

→ `station_迎客.glb`（若站名改「迎客驿楼」就用这个名）

### 3.2　东岭驿楼 · 开瓮勿逢陶谢

> 原句是"开陈年老酒最好别让酒友知道"。所以这张图的关键是**只有一只碗**：
> 一只黑釉半人高酒瓮，封泥裂开半边、瓮盖歪在旁边，瓮口露出酒面，
> 一支木勺插在瓮里，地上就一只陶碗。**不要**酒旗、不要第二只碗、不要酒坛阵列。

```
山岭台地上的小驿楼，单坡顶，木构白墙深暖灰瓦，体量比普通农舍小一号；
门前平场上立着一只半人高的黑釉陶酒瓮，瓮口的封泥裂开半边，
一片陶瓮盖歪倒在瓮脚旁，瓮口露出深褐色的酒面，一支木勺斜插在瓮里；
瓮旁地面上只放一只粗陶碗，别的什么都没有——不要酒旗、不要酒坛阵列、
不要第二只碗；驿楼檐下空着，不挂幌子不挂匾；
单人主体，正面偏右三十度，米白纯色背景，柔和暖秋午后侧光，
不出现任何人物，不出现任何文字；底面平整落地，宽约七米，深约五米，高约四米；
材质哑光无金属高光，写实摄影质感，浅景深，1:1 画幅，高清
```

→ `station_独饮.glb`

### 3.3　南溪茶寮 · 清溪浅水行舟

> `water_data.gd` 里这只碗是 `radius 22 / squash 3.2` 的狭长溪，顺着路走。
> 所以是**浅水、卵石滩、两岸低**——不是湖。木平台要伸到水边，
> 平台下系一条乌篷小船，船头搁在石阶上。

```
溪边一座三开间木构茶寮，竹席与深暖灰瓦混铺的低坡顶，白粉墙；
茶寮前的木平台向水边挑出两米，平台边用麻绳系着一条乌篷小船，
船头搁在一级伸进水里的石阶上，船舱里横放一支竹篙；
平台下就是浅水，能看见水底的卵石和细沙；
单人主体，正面偏右三十度，米白纯色背景，柔和暖秋午后侧光，
不出现任何人物，不出现任何文字、牌匾、招牌、幌子；底面平整落地，
宽约八米，深约六米，高约三米八；材质哑光无金属高光，
写实摄影质感，浅景深，1:1 画幅，高清
```

→ `station_溪渡.glb`

### 3.4　右岭岭台 · 隔江山寺闻钟

> 岭台上看不见江（见 §1「就近落地」第 1 条），所以模型自带的是**听得到**：
> 朝谷那一侧的石栏缺一段、敞向层叠青岭，台角木杆上挂一只小铜风铎。
> 铃要有挂绳，绳要垂着——Tripo 对细长悬挂物容易糊，这里给它一根粗一点的绳。

```
山脊最高处的一方石砌观景台，四角矮石栏，南面一整段石栏断开朝山谷敞开；
台面正中一块平石当坐凳，石面被坐得发亮；
台角一根粗木杆，杆头横挑一小截，横挑上用麻绳吊着一只小铜风铎，
铃下垂着两指长的穗绳，铃身有细密铭纹但不刻字；
台外是三层递远的青灰山岭和谷底薄雾；
单人主体，正面偏右三十度，米白纯色背景，柔和暖秋午后侧光，
不出现任何人物，不出现任何文字、牌匾、石碑刻字；
底面平整落地，宽约七米见方，高约三米五；石材哑光，铜面氧化发暗不反光；
写实摄影质感，浅景深，1:1 画幅，高清
```

→ `station_听钟.glb`

### 3.5　岭口凉亭 · 乞得名花盛开

> 「乞得」是费了力气求来的意思。所以花要**多、开满、有养过的痕迹**：
> 三盆，其中一盆根从盆底翻出来。盆不要太大——太精致的花盆会读成园林布景。

```
山口道旁的一座重檐小凉亭，六角攒尖顶，深暖灰瓦，木柱石础；
亭心一张方石桌，桌上摆三盆养了很久的名花：两盆重瓣牡丹开得正满、
一盆蜀葵抽到一人高，花瓣层次清楚、颜色沉而不艳；
其中一盆的根从盆底翻出来挂在外面，盆是素的粗陶盆，不是精致花盆；
亭外石阶两侧是成排的低矮野花，亭柱上缠着已经半干的旧藤；
单人主体，正面偏右三十度，米白纯色背景，柔和暖秋午后侧光，
不出现任何人物，不出现任何文字；底面平整落地，
宽约六米见方，高约四米五；材质哑光无金属高光，
写实摄影质感，浅景深，1:1 画幅，高清
```

→ `station_候花.glb`

### 3.6　西湾神苑 · 暑至临溪濯足

> 「濯足」的典出自屈原《渔父》，而这一站本来就叫**神苑**——所以石龛不能省。
> 濯足要看得见：**最后一级石阶是整块平的、刚好没进水面**，人站上去脚就在水里。
> 碗 3 是 `radius 26 / squash 1.5` 的湖湾，岸线要平缓。

```
湖湾静水边的一座小神苑，石砌小龛嵌进岸坡，龛内立一尊无字石碑；
龛前一座木构小殿，单坡顶深暖灰瓦，白粉墙，殿门敞开；
殿前石台向湖里伸出，最下一级是平整的石阶、刚好没入水面下一掌深，
石阶两侧长着低矮水草；阶上一只粗陶盆盛着清水；
单人主体，正面偏右三十度，米白纯色背景，柔和暖秋午后侧光，
不出现任何人物，不出现任何文字（石碑不刻字、殿门不挂匾）；
底面平整落地，宽约七米，深约六米，高约三米八；
材质哑光无金属高光，写实摄影质感，浅景深，1:1 画幅，高清
```

→ `station_濯足.glb`（原 `station_神苑.glb` 退役）

### 3.7　灯影亭 · 月下东邻吹箫

> 夜的一屏。但**出图时不要把整张图压暗**：Tripo 的 basecolor 是照着这张图
> 烘的，模型扔进白天的世界里，暗底色会读成一块黑。做法是"白天的光 +
> 灯笼点亮"——灯笼自发光，天色照常。
>
> 「东邻」是宋玉《登徒子好色赋》的东家之子，所以是**邻家传来的**一支箫，
> 不是亭子自己奏。模型上就是石桌上横放一支竹箫 + 一只陶埙。


## 4. 落库清单（出完图之后）

1. **先出图、后 Tripo。** 图片存进 `assets/models/` 时用
   `station_<站名>_source.jpg`，和导出出来的 basecolor（`station_<站名>_basecolor.jpg`）
   区分开——Tripo 会把 source 也当资源扫一遍。
2. `godot --headless --editor --quit-after 30` 扫一遍生成 `.import`。
   不跑这一步，后面 headless `load()` 会报 `No loader found for resource`。
3. `World3D.STATION_GLB_CONFIG` 追加 12 条。**`scale` 一律 10~12**，
   落地后跑一遍 `World3D._measure_station_aabb()`，脚底半宽要 ≤ 9.4m。
4. `road_data.gd` 的 `model_idx` 逐站改指（`FRAGMENT_STATION_TO_SLOT` 不动）。
5. `verify_station_roof.gd` 的 `HAND_MODELS` **必须重写**。它现在是
   `["驿楼","茶寮","岭台","神苑","凉亭","廊","亭灯"]` 这 7 个手工模型的名字，
   换掉之后这一条回归会**整张红**（找不到 `<站名>_roof` 材质），
   而 `STATION_ROOF_TINT` 对新模型本来也不生效——新模型的瓦色已经在图上定死了。
   这正是"两侧各自都绿"那一族里最容易安静溜过去的一处。
6. 回归：`verify_stations.gd`（GLB 存在 / `model_idx` 映射 / 站名牌）
   + `verify_interact_latch.gd` 第 8 节（**驿站占地不许骑进去**：
   半径要小于 `STATION_PASS_RADIUS` 15m，满速 15m/s 撞 3 秒钻不进去）
   + `lookdev_stations.gd` 看那 16 张 `ride_*`
   ——这一族的核心是"每一座站在骑行那一档有没有报出自己的名字"，
   而新模型的体量差异全在这一档才看得出来。
7. 站名若采纳 §1 的建议：`verify_story.gd`（`Localization.STRINGS` 中英对拍 +
   `3D_RIDE_DESIGN.md` 不许说谎），中英两份一起改。
