# 定妆照

`tools/lookdev_journey.gd`（玩家流程 23 屏）与 `tools/lookdev_grass.gd`（草皮 5 屏）
的**真产物**，不是手工摆的 mock。重新生成：

```bash
"$GODOT" --path . --script tools/lookdev_journey.gd    # → user://lookdev_journey/
"$GODOT" --path . --script tools/lookdev_grass.gd      # → user://lookdev_grass/
# 本目录是从那两个目录拷过来的
```

**两条都不能加 `--headless`、不能加 `--quit-after`** —— dummy renderer 不编译着色器、
也不做焦点路由，拍出来的图和玩家看见的不是一回事。两条脚本都自带像素断言，
所以它们同时也是回归（journey 27 条、grass 8 条）。

## 草皮（`lookdev_grass.gd`）

相机固定站在草环圆心、眼高 `EYE_H=1.6`（与玩家一致），`d` 是视线落点到相机的水平距离。

| 文件 | 这一屏在验什么 |
|---|---|
| `grass/04m.png` | **近景地面还露不露得出来**——这一屏就是「脚下那段地面」那条判据量的地方 |
| `grass/15m.png` / `grass/45m.png` | 中景：草与地皮的过渡，地形起伏还读得出来 |
